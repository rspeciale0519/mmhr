## Reading the matrix

- **Implemented locally:** The stated narrow behavior has application code and local evidence. This does not mean released.
- **Connected partial:** Application entry points reach part of the requirement. A material requirement or acceptance check remains.
- **Backend partial:** Commands, SQL, or persistence exist, but the complete user workflow is not connected.
- **Contract only:** Types, pure rules, projections, or interfaces exist. No complete operational implementation was found.
- **Evidence open:** Measurement or operational proof remains missing. A validator is not proof of compliance.
- **Deferred:** The PRD explicitly defers the requirement.

Counts describe requirements, not effort or a completion percentage.
Backend commands can still be exposed through authenticated SQL RPCs. Missing UI does not remove the need for authorization.
Test links identify relevant tests. Only the execution record in the report proves which tests ran on this date.
