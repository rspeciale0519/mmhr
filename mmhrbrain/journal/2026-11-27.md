### [15:50] Bold motion and interaction pass on the public site   (branch: claude/project-thread-9rznrd · PR #49)

**Synopsis:** Owner feedback on PR #49's preview (viewed in Chrome): "the site lacks in motion and interactive elements. It's a very basic website. I want to see far better movement, hover effects, and interactive elements." This supersedes the earlier "confident and crisp" motion level for the public site. Built a shared motion toolkit in `src/designs/cobalt/motion/` and used it on the chrome, shared blocks and all five public pages. Opus 5.5 high subagents wrote the code; the thread session planned, reviewed and ran the gates.

**What worked:** Evidence: `npm run type-check`, `npm run lint`, `npm test` (497 files, 5,763 tests), `npm run build`, and the four CI check scripts. Manual: Playwright sweep of `/`, `/how-it-works`, `/why-its-free`, `/for-providers`, `/resources`, `/contact` at 390px and 1440px: no horizontal overflow, one h1 each, no console errors, no reveal left waiting after a scroll-through or after a jump to the bottom. One toolkit agent first, then four page agents in parallel on disjoint folders against one shared dev server.

**What did NOT work:** Scroll reveals written as CSS scroll-driven animations (`animation-timeline: view()`) never run in Firefox or older Safari; all reveals now run from JavaScript. IntersectionObserver alone misses elements that go from below the screen to above it in one jump, so `reveal-observer.ts` also sweeps on scroll. `filter: blur()` on moving glows cost about 66 ms per frame in headless Chromium; live glows use a plain gradient. A sideways reveal start pose widens a 390px page; on narrow screens "left"/"right" rise instead. `overflow: hidden` stages can be scrolled sideways by a click; `.co-stage` uses `overflow: clip`.

**Artifacts:** `src/designs/cobalt/motion/` (API in `index.ts`), `landing/SixSteps.tsx`, `landing/FeeDemo.tsx`, `pages/how-it-works/MaskDemo.tsx` and `StepPicture.tsx`, `pages/why-its-free/ScoreInputs.tsx`, `pages/for-providers/ReplyPaths.tsx`, `pages/resources/Checklist.tsx` and `Glossary.tsx`.
