### [05:29] Fix Cobalt primary button text color   (branch: cursor/cobalt-primary-button-text-6528 · commits: fa64ba5)

**Synopsis:** Landing CTAs such as "Start free" and "Start your needs list" rendered navy on the blue primary gradient. `.co a { color: inherit }` is more specific than `.co-btn-p`, so Next.js `<Link>` buttons inherited `--co-navy`. The link inherit rule now skips button-styled anchors, and `a.co-btn-p` keeps `--co-on-primary` (#fff) for link/hover/focus/active and `.dark`.

**What worked:** Evidence: `npm run type-check`, `npm run lint`, `npm test` (5,516 tests), `npm run build`, `npm run test:e2e` (17 Playwright tests, including computed `rgb(255, 255, 255)` on the landing CTAs at 390px and 1440px, hover/focus, and `.dark`). Manual: before color was `rgb(13, 26, 74)`; after was white. Ghost buttons stayed navy.

**What did NOT work:** jsdom does not resolve `var(--co-on-primary)` to rgb, so the unit test asserts the winning declaration rather than a computed rgb value. Real computed color is covered by Playwright.
